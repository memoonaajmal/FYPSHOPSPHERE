# 🛍️ ShopSphere — FYP Project

ShopSphere is an **e-commerce platform** with **AI**, **AR (Augmented Reality)**, and **Live Stream** features — built using **Next.js**, **Node.js**, and **MongoDB**.

---

## 🚀 Getting Started

### 🧩 Prerequisites
Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v18 or higher)
- [npm](https://www.npmjs.com/)
- [MongoDB](https://www.mongodb.com/)

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the Repository
Open your terminal and run:
```bash
git clone https://github.com/memoonaajmal/FYPSHOPSPHERE.git
cd FYPSHOPSPHERE
````

---

### 2️⃣ Create the Database

* Open **MongoDB Compass** or your terminal.
* Create a new database named:

  ```
  shopsphere
  ```

---

### 3️⃣ Backend Setup

#### Step 1: Move to backend folder

```bash
cd backend
```

#### Step 2: Run all setup scripts by one command

```bash
npm run setup
```

#### Step 3: Start the backend server

```bash
node src/server.js
```

Your backend should now be running.

---

### 4️⃣ Frontend Setup

#### Step 1: Open a new terminal and move to frontend

```bash
cd frontend
```

#### Step 2: Start the frontend

```bash
npm run dev
```

Your frontend should now be running.

---

## 🧠 Notes

* Make sure the backend is **running first** before starting the frontend.
* Default ports and configuration are defined in `.env` and `.env.local` files.
